# Contributing to mailme

Thank you for your interest in improving `mailme`! Contributions are welcome.

## Getting Started

1. **Fork and Clone**: Fork the repository on GitHub and clone your fork locally.
2. **Prerequisites**: Ensure you have [Go 1.22+](https://go.dev/dl/) installed.
3. **Branch**: Create a new branch for your feature or bug fix:
   ```sh
   git checkout -b feature/my-new-feature
